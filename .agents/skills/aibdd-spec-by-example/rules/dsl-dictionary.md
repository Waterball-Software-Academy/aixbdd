# DSL 字典表（用詞一致的 SSOT）

跨句一致性只約束「用詞」，不約束「句型」：同一業務概念全 package 只用一種寫法；句子的形狀為各自的測試意圖最佳化，同語意不必沿用同一句式。相似的 step 句各自保留、不需要合併或對齊——情境好讀是最高目標。

## 位置與結構

每個 function package 一份：`${TRUTH_BOUNDARY_PACKAGES_DIR}/<NN-package>/dsl-dictionary.md`，以 `assets/templates/dsl-dictionary.template.md` 為模版。每個業務概念一列：詞、類型（實體／動作／狀態／欄位）、一句定義、禁用同義詞（曾出現但不採用的寫法）。

## 約束

1. 草擬每句前查表：概念已在字典 → 必用字典的詞，不得換同義詞（「客戶」不得寫成「會員」「user」）；概念不在字典 → 選定一個業務詞加進字典草稿，隨 Example 一次寫入。
2. 兩詞疑似同概念（如「任務」與「目的」字面近似）→ 先讀完整 feature 與字典判定是否真為兩個概念；拿不準蒐集成 `$ASK_BATCH` 交 clarify，不逕行合併或並存。
3. 字典管詞不管句：`$DSL_CORPUS` 的既有 format 是句式參考、非約束；沿用與否以本例好讀為準。
4. 禁用同義詞欄要維護：澄清後淘汰的寫法記進該欄，之後的批次才不會再犯。
